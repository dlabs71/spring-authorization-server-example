# Тестовый OAuth2 клиент.

Предназначен для демонстрации авторизации и получения информации о пользователе через `j-sso`.

URLs:

- http://localhost:8080/login - вход

## Сборка и запуск приложения

Для сборки приложения вам потребуется Node 16 и npm 8. Перейдите в директорию `test-client` и выполните
следующие команды.

```shell
npm install
npm run build
```

Для запуска приложения используйте следующую команду в директории `test-client`:

```shell
npm run serve
```

Обратите внимание, что приложение будет работать на порту 8080. Порт можно поменять
в [vue.config.js](client/vue.config.js).

Если вы поменяли порт приложения не забудьте поменять его в поле `redirect_uris` таблицы `sso.system_oauth2_clients_v2`.

Приложение имеет ряд параметров указанных в файле [.env.development](.env.development). При изменении настроек OAuth2
клиента в админке j-sso необходимо применить эти изменения и здесь.

| Параметр                    | Описание                                                                                                                                                            |
|-----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| VUE_APP_OAUTH_REDIRECT_URI  | URL перенаправления указывающийся при настройке OAuth2 клиента в админке j-sso. Также его можно найти в поле `redirect_uris` таблицы `sso.system_oauth2_clients_v2` |
| VUE_APP_OAUTH_CLIENT_ID     | Параметр client_id используемого OAuth2 клиента                                                                                                                     |
| VUE_APP_OAUTH_AUTH_HEADER   | Значение `Authorization` заголовка для запросов авторизации (/oauth2/authorize)                                                                                     |
| VUE_APP_OAUTH_URL           | URL подключения к j-sso                                                                                                                                             |
| VUE_APP_OAUTH_CLIENT_SECRET | Параметр client_secret используемого OAuth2 клиента                                                                                                                 |
